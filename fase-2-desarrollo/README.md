# Fase 2 — Desarrollo

Aquí vive la aplicación completa.

| Carpeta | Contenido |
|---|---|
| `backend/` | API REST — Node 22, Express 5, Prisma, PostgreSQL + PostGIS |
| `mobile/` | App Expo — un solo código para Android, iOS y web |
| `docs/` | Arquitectura, modelo de datos, diagramas UML, plan de pruebas y documentos de cada sprint. Empieza por [`docs/README.md`](docs/README.md) |
| `entrega/` | Lo que se presenta en la evaluación: guía de la asignatura, documentos individuales y presentación |

Para levantarla, desde la raíz del repositorio: `docker compose up --build`.
La guía técnica completa está en [`DESARROLLO.md`](../DESARROLLO.md).
